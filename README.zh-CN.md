# Online Duration Counter (ODC)

适用 Minecraft Java **1.21.11 / Fabric / Java 21及以上**。作者：**GPT-6.1 Sol、wiknzylix**。

## 安装与设置

房主与需要显示侧栏的朋友将 `OnlineDurationCounter-1.0.5+mc1.21.11.jar` 放入各自游戏实例的 `mods` 文件夹，并安装适用于1.21.11的 Fabric API。升级时替换旧版ODC JAR，不要同时放入两个版本。Fabric Loader至少0.18.4。按默认快捷键 **Y** 打开配置，也可通过 Mod Menu 17.0.0 打开。真人历史保护由房主/服务器执行，建议房主和朋友一起更新到1.0.5。

照常开放局域网并使用 SakuraFrp 转发，无需开启作弊。ODC不改变联机验证模式，沿用现有 LAN 辅助模组和登录方式。

## 显示

侧栏标题为“在线时长”，采用比正文更大的字号；小字号副标题“Have Fun”使用原版斜体修饰。在线玩家使用柔和绿色，排在离线灰色玩家之前；两组分别按累计时间降序排序、分别编号。同时间按名字和UUID稳定排序。

每个人可单独开关侧栏、选择显示全部或勾选的玩家、调整宽度、最大高度和字号、调整0–100%的**背景不透明度**（0完全透明、100完全不透明）。默认宽度 **60** GUI单位、最大高度 **142**、正文字号 **0.35倍**、背景30%，位置紧贴右下角。宽度可调60–1200，最大高度40–1200，字号0.35–3倍；最终显示限制在屏幕内。默认格式为 `X小时X分`，还可选 `X小时X分X秒` 或 `X小时`。这些设置只影响本机；关闭显示、筛选掉玩家均不停止计时。

修改后应用到侧栏，编辑位置时可查看实际样式。背景会随行数紧凑收缩，标题区和玩家行距进一步压缩；底部不再显示“还有XX人，可在设置中筛选”。内容超过最大高度时，优先显示在线玩家，可增加高度、减小字号或筛选玩家；窄宽度时姓名省略、时间适当缩小以避免互相覆盖。原版侧栏已有可见内容时，ODC让位；按F1也隐藏ODC。

## 配置、颜色与拖动尺寸

设置只有“显示”和“玩家”两页，采用紧凑深色分区。显示页可以更改尺寸、字体、背景、时长格式及配置快捷键。主标题、副标题、在线玩家和离线玩家有独立的 `#RRGGBB` 颜色输入与色块，“恢复默认颜色”只恢复四色，不重置布局、尺寸或规则。

右侧滚动条可拖动滑块，也可点击轨道跳转；鼠标滚轮同样可用。颜色页没有额外说明小字，仅在颜色输入无效时提示错误。

点击“编辑侧栏位置”，可拖动内容移动侧栏；拖动虚线边框的四边或四角手柄可调整宽高。虚线框表示最大高度，实际背景仍随可见玩家行收缩。方向键逐GUI单位微调位置，Shift＋方向键每次移动10单位；Esc或完成保存返回。位置按屏幕可用移动范围的比例保存，改变窗口尺寸和GUI缩放后保持相对位置并限制在屏幕内。

“打开配置界面快捷键”默认Y，可在显示页直接录入键盘或鼠标按键，Esc取消录入，Delete/Backspace清除。实际冲突会提示对应功能。旧版侧栏开关键已移除，显隐改为在显示页点击“显示侧栏”。快捷键录入期间不会打开重复配置界面。

升级会保留时长和玩家筛选。旧版未改动的默认宽高、字号与右侧居中位置会迁移为新版默认参数，非默认自定义值保留；可通过“恢复显示默认值”重新采用新版默认布局。已自定义的打开配置快捷键保留；旧版未绑定状态会首次迁移为Y。

## 玩家选择与规则

玩家页左侧为“全部玩家”“全选”“反选”“清空选择”和“规则”；右侧为更密集的玩家列表。选中与未选中使用不同的低饱和背景及勾选标识，在线/离线单独显示，鼠标悬停可查看UUID。

“全部玩家”会包含后来加入的玩家；“全选”只选择目前已有的记录。“反选”按已知玩家的手动选择取反。“规则”支持以下任意条件匹配：

- 关键词：ID包含任意关键词即匹配，不区分大小写，多个关键词用逗号、分号或换行分隔。
- 正则表达式：使用不区分大小写的Java正则查找；无效表达式会显示提示并仅忽略这一项，其他规则继续生效。
- 纯数字ID：只由ASCII数字0–9组成的名字。
- Carpet假人：在线时按服务端实际实体类型识别，不按名字或UUID猜测。已识别的纯假人离线后仍可屏蔽；有真人历史的UUID退出假人会话后恢复真人记录。身份历史随世界账本与QB回档保存。

“自动屏蔽匹配玩家”默认开启；只要规则有匹配内容，就会从本机侧栏中排除，手动勾选不会覆盖自动屏蔽。“选中匹配”把选择集替换为规则匹配项；“取消匹配”从当前手动范围移除匹配项。若需要仅显示匹配项，请先关闭自动屏蔽再用“选中匹配”。规则与选择按世界保存。**屏蔽仅隐藏侧栏记录，关键词、正则、数字ID和假人规则都不停止后台计时，也不删除数据；取消屏蔽即可重新看到完整累计时长。**

四类规则同时过滤在线栏和离线栏，已识别的纯假人下线后仍可屏蔽。位置编辑器同样使用过滤后的记录；已有存档数据全部被隐藏时显示空列表，不会补入演示玩家。只有未取得世界数据时才显示演示名单。配置页的完整玩家名单保留，便于重新选择和解除屏蔽。

## 离线身份与真人代上线

玩家列表每行有“自动 / 真人 / 假人”按钮，点击循环。它按当前世界和UUID保存在本机：自动使用服务器结果；真人覆盖该记录的假人标签；假人可以补标安装ODC前就离线的机器人。启用“屏蔽假人”后，手动标记同样作用于在线与离线栏。身份按钮只改变假人规则的匹配，关键词、正则、纯数字规则和手动勾选仍各自生效；不改玩家实体、登录验证或时长数据。

从1.0.5开始，服务器记住在本世界实际观察到的真人UUID。这个UUID后来由Carpet假人代上线时，在线阶段仍按假人处理；假人退出后，离线记录恢复真人身份，不会仅因为这次代上线就被“屏蔽假人”隐藏。纯假人UUID离线后仍保留假人身份。同一UUID的时长继续合并，不拆分或清除已有累计。

首次安装前的离线记录不能全部自动判断：原版统计和Carpet普通玩家数据没有可靠的历史真假标签，正版UUID、皮肤、名字或存档存在与否都不能作为真人证据。已在旧版被最后一次假人会话覆盖的真人历史也不能凭空还原；让真人再正常加入一次，或在本机把该记录设为“真人”。已知的旧离线假人可以直接设为“假人”，无需专门召唤上线。

Carpet的 `/player 玩家名 spawn` 按其解析出的UUID读取玩家数据。混合认证环境中，同名不保证同UUID；ODC只保护同一个服务器UUID的真人历史，不会按名字合并不同账户。

身份识别依据：[Carpet 1.4.194官方实现](https://github.com/gnembon/fabric-carpet/blob/1.4.194/src/main/java/carpet/patches/EntityPlayerMPFake.java)。

## 计时与历史

安装后按服务器确认的真实在线时间累计，低TPS不使计时变慢，挂机也计时。死亡、重生、换维度不重置。房主尚未开放局域网时独自游玩也计入；真正的单人暂停不计，开放局域网后ESC没有暂停世界则继续计时。退出存档或服务器关闭期间不计时。网络突然断开以服务器识别离开的时刻为准。

Carpet假人离开服务器时立即结算并转为离线，停止累计；同UUID再次上线时接着原有总时长计时。1.0.3同时观察原版玩家移除入口，修复假人绕过普通断线事件后仍显示在线并继续累计的问题；普通玩家的两个离线通知会去重。

首次读取本存档仍存在的原版 `stats/<UUID>.json` 中 `minecraft:play_time`，以20tick=1秒折算历史；每个UUID只导入一次，之后使用ODC自己的会话账本。旧数据无法还原低TPS期间的真实秒数，也无法恢复被删除的统计或其他存档的时长。未知名字暂用短UUID显示，再次加入后自动更新名字。

服务器每60秒校准客户端数据，加入、离开和暂停切换时额外同步。可选的秒显示只在客户端根据服务器基准推算，不提高服务端写盘或同步频率；网络延迟会使不同电脑的瞬时显示有小幅差异，最终累计以服务端账本为准。客户端不会上传时长。

## QB备份与回档

账本位于 **`<世界存档>/data/odc-online-duration.json`**，有效副本是同目录的 `.bak` 文件。QB备份时应包含整个世界的 `data` 目录，不能在QB排除列表中排除这两个文件。

ODC在原版世界保存屏障处保存并排空写盘任务；备份工具临时禁止世界保存期间，不发起周期写入。关闭世界时结束全部会话并等待旧写盘线程结束。回档重新打开世界时只读取备份中的账本，不把未来的内存累计值取最大值写回。因此**时长随存档回退**。

服务端的真人/假人历史也随世界回退；本机三态身份校正与其他显示偏好一样保留，不写入服务器存档。

例如100分钟时备份，游玩至200分钟后回档，应从备份中的约100分钟继续。恢复到安装ODC以前的备份时，从那个备份中的原版统计重新导入。客户端显示设置保留，时长缓存会清空。

上述适配依据 QuickBackupMulti-Reforged 1.21.11 的“关闭世界→恢复文件→重新打开”流程实现，无需安装额外兼容补丁。不要在服务器仍运行时手动覆盖账本文件。

正常每60秒异步保存，下线也提交保存，关服等待最终保存。强制结束进程或磁盘故障可能损失上次成功保存后的时长。主文件损坏时尝试有效备份；两份均不可读时停止该世界的ODC计时并记录错误，不覆盖损坏文件。

## 账号与生电

ODC用服务器实际UUID作为主键，不查询皮肤站，不自动按同名合并。正版、离线、LittleSkin只要在现有环境中正常加入，就使用同一个服务器权威计时系统。切换认证方式或更改离线名字可能产生新UUID，旧记录仍保留，但不会擅自认作同一个人。

ODC不创建世界计分板、不执行命令、不修改红石或方块更新、不加载额外区块、不修改随机刻、游戏规则或tick速度。暂停钩子只观察状态。任何软件均有少量执行成本，不能用源码检查代替你实际整合包的MSPT对照测试。

## 构建

使用Java21、Gradle9.2.0、Loom1.14.10，执行 `gradlew.bat build`。测试包含会话、暂停、重复导入、回档及真实账本文件恢复。开发工具、测试世界及缓存不属于需要安装的模组文件。

图标使用内置imagegen生成，提示词：简约像素时钟结合排行榜，原版Minecraft界面风格，低饱和炭灰、米白及少量柔和绿，透明背景，无文字。
